# Canon: issue bodies state present-tense facts — never aspirational as shipped

Issue bodies (and kickoff restatements) state **present-tense facts with evidence**.
Planned work is written as scope ("this issue adds X"), never as an existing
artifact ("X exists" / "#N shipped Y"). Referencing another issue's deliverable
requires that issue's **actual current status, checked at write time**. An
aspirational body is a false record the moment it is filed.

Surfaces: `/vl-plan` kickoff/grounding, `/vl-chip` (when authoring or amending
bodies), `/vl-start-feature` + `/vl-update-docs`, orch seat kickoff/ad-hoc issue
templates, and planner/orch site prompt parity. Receipt inspiration: anduin #395 /
#400 (asserted shipped artifacts that did not exist / were still open).
